# Zwierzak i podsumowanie postępu: plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** zwierzak w stylu Tamagotchi (gąska lub kaczuszka) i ekran postępu w Mierze, reagujące na wpisy użytkownika.

**Architecture:** logika i rysowanie w nowym `pet.js` (globalny `var PET`), bez dostępu do globali `app.js`:
dane dostaje przez obiekt `ctx`. `app.js` buduje `ctx`, wstawia kartę i ekran, wywołuje `PET.react`.
Kod powstaje w `miara` (prywatne); do `miara-pwa` trafia przez `tools/sanitize_miara.py`.

**Tech Stack:** JavaScript bez bibliotek, SVG w kodzie, CSS `@keyframes`, Node (`tests/smoke.js`), Python Playwright (`tools/test_uzytkownika.py`).

**Spec:** `docs/specs/2026-11-05-zwierzak-design.md`

## Global Constraints

- CSP `'self'`: żadnych zewnętrznych zasobów, żadnych `<script>` ani `on...=` w HTML (test dymny to sprawdza).
- Klucz `talerz-trening-v1` bez zmian; nowe pola w `DEF`: `pet:null`, `body:false`, `petSeen:[]`.
- Każdy tekst z danych użytkownika (imię zwierzaka) przez `esc()`.
- `@media (prefers-reduced-motion: reduce)`: wszystkie animacje zwierzaka wyłączone.
- Kolory tylko z istniejących zmiennych CSS (`--green`, `--line`, `--warn-bg`, `--warn-ink`, `--bg`, `--ink`).
- Nastrój i wskaźniki nie zależą od wagi ani kalorii.
- Commity: autor `slashdev-ops`, bez `Co-authored-by` (pilnuje hook `commit-msg`).
- Gramatyka: gąska i kaczuszka rodzaju żeńskiego; imię domyślne `Kluska`.

## Review Focus

1. Stare dane i importowane kopie bez `S.pet`: karta zaprasza do wyboru, żaden widok nie rzuca błędu (Task 3).
2. Imię z `<`, `>`, `"` i imię puste: wyświetlane bezpiecznie, puste zastąpione `Kluska` (Task 3).
3. Okolice północy: o 00:30 mina `sleep`, `przerwa` liczona od wczoraj, wczorajsze wpisy nie znikają (Task 1).
4. Ten sam kamień milowy po odświeżeniu: świętowanie tylko raz, bo id trafia do `petSeen` (Task 3).
5. `prefers-reduced-motion`: brak animacji (Task 2, kontrola CSS w teście dymnym).

check('pet: wzrost wagi nie zmienia humoru', st(mk({today:{pts:40,w:80}})).meters.mood===st(mk({today:{pts:40,w:84}})).meters.mood);
// 30 dni z pts 30, potem 10 pustych, since 40 dni temu
check('pet: 30 aktywnych dni + 10 pustych => adult', st(mk({active:30, empty:10})).stage==='adult');
// weekPts 120 => level Brąz
check('pet: Brąz w tygodniu => szalik', st(mk({weekPts:120})).acc==='szalik');
